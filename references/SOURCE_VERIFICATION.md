# Source verification record

**Verified:** 2026-07-16  
**Scope:** paper titles, identifiers, official documentation locations and primary GitHub repositories used by this package.

## Method

- Primary arXiv pages or publisher pages were used for paper titles and abstracts.
- Official platform/provider documentation was preferred for runtime and API behavior.
- Paper-linked or organization-owned GitHub repositories were preferred for related code.
- Repositories are not vendored and their current licenses were not copied into this archive; license review remains an adoption gate.
- 2026 papers should be treated as preprints unless a venue is explicitly listed.

## Important limitations

- Source verification does not reproduce experimental results.
- A repository can change after this verification date; pin and review an exact commit before adoption.
- Reported model or benchmark improvements do not establish Operator Kit suitability.
- The package has not inspected Operator Kit’s private repository, deployment state, provider credentials or production data.
- Official API documentation must be re-read immediately before implementation and release because behavior, limits and schemas can change.
