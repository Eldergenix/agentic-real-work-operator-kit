# HCOM model program

The learned system is subordinate to deterministic authority. Models may update a probabilistic belief, predict transitions/outcomes, retrieve procedures, rank finite candidates, or veto for risk. They do not create targets, permission, consent, budgets, credentials, or provider effects.

## Stages

1. Data-readiness and deterministic/statistical baselines.
2. L1 calibrated predictors.
3. Procedural world model and selective foresight.
4. Finite eligible-candidate ranker.
5. Safe contextual-bandit canary with known propensities.
6. Receding-horizon constrained MPC: simulate, certify one effect, execute, read back, update, repeat.
7. Dreamer-style challenger only after action-conditioned data, mature outcomes, stable reward definitions, overlap, tail-risk tests, and rollback proof.

`model-tournament.yaml` prevents architecture-by-name. `promotion-policy.yaml` separates reliability, decision quality, and current runtime risk.
