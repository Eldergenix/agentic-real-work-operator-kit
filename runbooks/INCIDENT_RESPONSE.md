# Operator incident response

1. Classify severity and affected capability cells/providers/users.
2. Activate the narrowest sufficient kill switch; severe authorization/privacy/material-loss incidents demote immediately.
3. Stop new attempts while permitting safe reconciliation of in-flight unknown effects.
4. Preserve append-only events, provider evidence and deployment/model/policy refs.
5. Reconcile every affected `uncertain` action; compensate or mitigate where registered.
6. Notify users with exact known/unknown state and consequence.
7. Close the evidence epoch and invalidate incompatible promotion evidence.
8. Patch and run fault/security regression suites.
9. Rehearse rollback and re-enable only after incident closure and re-earning policy.
