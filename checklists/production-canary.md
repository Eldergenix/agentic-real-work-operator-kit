# Production Canary Checklist

- [ ] Canary owner/on-call assigned.
- [ ] Exact provider/test or staff accounts enumerated.
- [ ] Capability cells, maximum count, financial/consequence exposure, and time window signed.
- [ ] Current mandate, consent, connector, policy, adapter, model, and deployment epochs verified.
- [ ] Required verifier grade and maturity horizon defined.
- [ ] Provider and UI teardown/recovery prepared.
- [ ] Global/domain/capability kill switches tested.
- [ ] Database backup and schema rollback evidence present.
- [ ] All four Worker refs/bindings/secret-name sets verified.
- [ ] Installed TestFlight build/ref and compatibility verified.
- [ ] Provider timeout-after-commit and duplicate-delivery drills pass.
- [ ] Revocation during execution drill passes.
- [ ] Reconciliation and compensation queues are healthy.
- [ ] Sequential risk/incident monitoring active.
- [ ] End-of-canary provider objects and receipts reconciled.
- [ ] Signed canary closeout/go-no-go recorded.
